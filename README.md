# Outbreak Radar

Early warning for hostel food and water-borne illness. 12-hour hackathon POC, MUJ.

**Read [AGENTS.md](./AGENTS.md) before writing any code.** It holds the shared contract,
who owns which directory, and the Next.js 16 gotchas.

```bash
npm install
npm run dev           # http://localhost:3000
npm run detect:test   # verify all four detection scenarios, terminal only
npm run typecheck
```
